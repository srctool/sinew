# Changelog

Every module is released at one version, so one changelog covers a release. Until 1.0.0 is out, the changes are in each repository's changelog:

- [Sinew for Kotlin](https://github.com/srctool/sinew-kotlin/blob/main/CHANGELOG.md)
- [Sinew for Dart and Flutter](https://github.com/srctool/sinew-dart/blob/main/CHANGELOG.md)

:::info[Versioning]

Sinew follows semantic versioning. A mistake in a released version is never deleted: it gets a patch release.

:::
