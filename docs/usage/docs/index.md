# Using Sinew

Sinew is a plug-and-play app architecture for Kotlin Multiplatform and Flutter. It ships the plumbing every app rewrites (response mapping, results, a coded and localized error model, paging, presentation base classes, an HTTP client with token refresh, secure storage, and developer tools) as small packages you add one by one. Sinew ships the mechanism; your app ships the configuration.

These docs are for developers **using** Sinew in an app: adding the packages, wiring them, and building a screen on them.

:::info[Not released yet]

Sinew has no published release yet. The guides here (installation, wiring, your first paged list) are written with the first release, 1.0, when the API they show is real.

:::
