# Sinew contributor docs

Design, architecture and implementation docs for people building Sinew. The Guide pages are generated from the design notes:

```bash
python3 scripts/sync_vault.py <path-to-sinew-notes>
```

```bash
npm install
npm run start
npm run build
```

The usage site (docs/usage) links here only through Contributing; set this site's address with `SINEW_INTERNAL_URL` (default `http://localhost:3000`).
